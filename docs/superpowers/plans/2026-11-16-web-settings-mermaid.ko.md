# 웹 설정과 Mermaid 수정

[English](2026-11-16-web-settings-mermaid.md) | **한국어**

목표: 설정 톱니바퀴가 실제 Mac 스타일 환경설정 대화상자를 열고, Mermaid 텍스트가 정렬을 유지하며 테마의 레이블이 읽기 쉬워야 한다.

사용자 지시: Mac 앱에 맞추는 구현을 이어간다. 추가 디자인 승인 절차 없이 기존 React/CodeMirror/Mermaid로 직접 구현한다.

- [x] 스크린샷의 다이어그램을 재현하고 Aside에서 SVG 텍스트 정렬과 레이블 색상 근거를 수집한다.
- [x] 화면 모드, 편집기 크기, 줄 번호/줄바꿈, Mermaid 스타일과 테마에 대해 검증된 브라우저 환경설정과 접근성 있는 모달을 추가한다. 초안을 변경하거나 NAS에 쓰지 않고 즉시 적용하며 새로고침 후에도 유지한다.
- [x] Mermaid 스타일시트와 인라인 스타일에서 안전한 SVG 표현 선언만 보존한다. 리소스 제한, 스크립트 제거, foreignObject 제거, 불투명 iframe 및 CSP를 유지한다. 렌더링 글꼴을 일치시키고 Mermaid 작업을 직렬화하여 이전 렌더링이 새 설정을 덮어쓰지 못하게 한다.
- [x] 회귀 테스트, 프런트엔드 빌드, Aside 데스크톱/모바일 및 라이트/다크 설정 흐름, 레이블 위치/색상, 시스템 모양과 영속 저장을 검증한다.
- [x] 최종 diff를 검토하고 새로운 불변 0.4.1 다중 아키텍처 이미지를 게시한 뒤 매니페스트/런타임을 검증한다.

검토 중점: 비동기 렌더링 중 빠른 환경설정 변경, 신뢰할 수 없는 SVG CSS URL/at-rule, 초안 보존, 모달 키보드/포커스 처리, 명시적 테마가 선택된 동안의 시스템 색상 변경.

검증: 프런트엔드 테스트 46개, 백엔드 테스트 223개, 프로덕션 프런트엔드 빌드 및 Compose 검증을 통과했다. localhost:5173의 Aside에서 데스크톱 1440×1000 및 모바일 390×844로 설정 모달, 스타일/테마 갱신, 도형 경계 안에 있고 중심에서 0.4 CSS 픽셀 이내로 정렬된 6개 노드 레이블 전부, 전경/배경이 구분되는 4개 간선 레이블, 줄 번호/줄바꿈/글꼴 크기, 새로고침 후 영속 저장 및 오류 없는 브라우저 콘솔을 검증했다. 키보드/포커스/배경 영역/초안 보존과 실시간 시스템 모양에는 자동화된 테스트가 있다. 독립 검토에서 P1/P2 문제를 발견하지 않았으며, Aside에서 flowchart, sequence 및 gitGraph 스타일을 원래 Mermaid 출력과 추가로 비교했다. 실제 NAS 쓰기는 수행하지 않았다.

게시: 내부 테스트 레지스트리 이미지(0.4.1), 인덱스 sha256:a6649c5e91a1de97b43f7219dacca1f0caa38f947606a3eca3f41e04e4ef4b33. linux/amd64와 linux/arm64 이미지를 모두 플랫폼 매니페스트 다이제스트로 받아 설치 버전 0.4.1, HTTP/HTTPS 세션/읽기, 정적 자산, 그래프 라우팅, Markdown 계약, UID 및 비공개 모드 스모크 검사를 통과했다. 프로덕션 NAS/컨테이너 배포는 변경하지 않았다.
