# Synology Markdown Note 1.2.15 (빌드 26)

[English](1.2.15.md) | **한국어**

Markdown 편집기에서 `[[`를 입력할 때 나타나는 노트 링크 자동완성 팝업의 가독성과 위치를 개선했습니다.

## 변경 사항

- 자동완성 목록에 불투명한 시스템 배경색과 테두리·그림자를 적용했습니다. 라이트·다크 모드 모두 지원합니다.
- 팝업을 편집 커서의 오른쪽 아래에 우선 표시하고, 공간이 부족하면 화면 안에 들어오도록 위치를 조정합니다.
- 스크롤·창 크기 변경 시 위치를 갱신하고, 커서가 편집기 표시 영역 밖으로 이동하면 목록을 숨깁니다.
- 검색 결과 수에 따라 팝업 높이를 조정하며 기존 링크 검색 창 동작은 유지합니다.

## 검증

- 이전 세션에서 Swift 전체 회귀 테스트 327개(35개 스위트) 통과. 팝업 위치, 화면 가장자리, 실제 편집기 렌더링, 스크롤 및 배경 불투명도 테스트를 포함합니다.
- 라이트·다크 테마별 합성 테스트 편집기 화면을 PNG로 렌더링해 확인했습니다.
- 기존 릴리스 준비 과정에서 Swift·CLI 테스트와 패키지 서명·체크섬 검증을 별도로 수행했습니다. GitHub 배포용 패키지는 재검증이 필요합니다.
- 설치된 운영 앱과 NAS 데이터의 실제 동작을 변경하거나 검증하지 않았습니다.

## 배포 범위

macOS 14 이상 Apple Silicon arm64 앱 DMG·ZIP과 Ubuntu 22.04/24.04 amd64 및 macOS arm64 CLI를 배포합니다. 앱은 기존 로컬 개발 인증서로 서명하며 Apple Developer ID 서명·공증은 포함하지 않습니다.
