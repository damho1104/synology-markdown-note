# Synology Markdown Note 1.2.16 (빌드 27)

긴 Markdown 문서를 스크롤한 뒤 편집할 때 스크롤 위치가 불필요하게 이동하던 현상을 개선했습니다.

## 변경 사항

- 글자를 입력할 때 전체 문서에 Markdown 서식을 반복 적용하는 동작을 줄였습니다. 텍스트와 글꼴 크기가 그대로면 재적용을 생략합니다.
- 서식을 별도 속성 문자열로 계산하고 기존 서식과 비교하여 실제로 달라진 범위만 갱신합니다.
- 첨부파일과 원본 블록 토큰 속성을 유지하고, Undo/Redo 후 Markdown 강조 스타일을 복원합니다.
- 한국어 입력기 조합 중 서식 변경을 억제하는 기존 동작을 유지합니다.

## 검증

- 스크롤된 240줄 문서에서 연속 입력 중 화면과 커서 위치를 검증하는 회귀 테스트를 추가했습니다.
- Markdown 문법 삭제 및 Undo 이후 서식 복원을 검증하는 회귀 테스트를 추가했습니다.
- 릴리스 소스에서 Swift 전체 회귀 테스트 329개(36개 스위트), CLI 테스트 100개가 통과했습니다.
- 기존 릴리스 준비 과정에서 패키지 서명·체크섬 검증과 플랫폼별 빌드를 별도로 수행했습니다. GitHub 배포용 패키지는 재검증이 필요합니다.
- 실제 사용 중인 앱 설치 및 NAS 데이터 변경은 수행하지 않습니다.

## 배포 범위

macOS 14 이상 Apple Silicon arm64 앱 DMG·ZIP과 Ubuntu 22.04/24.04 amd64 및 macOS arm64 CLI를 배포합니다. 앱은 로컬 개발 인증서로 서명하며 Apple Developer ID 서명·공증은 포함하지 않습니다.
