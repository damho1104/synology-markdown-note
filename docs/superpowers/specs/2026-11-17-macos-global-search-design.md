# macOS 전체 검색 팝업

사용자 요청: 웹과 다른 맥앱 돋보기 동작을 맞추고 hotfix 브랜치에서 구현한다.

- 돋보기와 기존 ⇧⌘F 메뉴는 어느 화면에서든 독립 SwiftUI 시트를 연다. 열면 검색창에 포커스하고 Esc/닫기로 취소한다.
- 휴지통을 제외한 전체 노트의 제목·미리보기·태그 및 이미 내려받은 본문을 검색한다. 검색 때문에 NAS 본문을 내려받지 않는다. 수정 날짜 내림차순, 결과 수 및 처음 100개 표시 안내를 제공한다.
- 팝업의 검색어는 기존 목록·고급 검색 상태를 변경하지 않는다. 결과를 열면 전체 목록으로 이동하고 검색/고급 조건을 해제한다. 공통 뒤로/앞으로로 기존 메모장·검색·그래프 상태를 복원한다.
- 입력 변경/닫기/계정 전환 뒤 늦게 끝난 검색은 표시하거나 선택하지 않는다. 검색 중에는 이전 검색 결과를 열 수 없다. 계정 전환 시 팝업을 닫는다.
- 기존 목록 검색, 고급 검색, 데이터 저장·동기화 방식은 유지한다. 웹/CLI 변경과 설치·버전 변경·배포는 범위 밖이다.

접근 비교: 기존 목록 검색창으로 이동하는 방식은 화면/필터에 종속되어 요구에 맞지 않는다. 별도 창보다 기존 메인 창의 SwiftUI 시트가 웹 팝업 및 앱의 다른 선택 시트와 일관되므로 채택한다. 웹과 같은 메타데이터 검색에 맥앱의 기존 로컬 본문 색인을 함께 사용한다(구현 판단).

검증: 필터 독립성·본문/미리보기/태그·휴지통 제외·정렬·빈/공백 검색어·취소 및 원래 상태 불변을 임시 로컬 저장소로 검사한다. 검색 결과에서 이동한 뒤 공통 이력 복원을 검사한다. Swift 전체 테스트와 앱 번들 빌드 후 격리 데이터로 실제 버튼·단축키·닫기·결과 열기를 확인한다. Git 커밋·태그·푸시는 수행하지 않는다.
