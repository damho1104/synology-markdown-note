# Synology Markdown Note 1.0.0

**English** | [한국어](1.0.0.ko.md)

First 1.0 release. Apple Silicon (arm64), macOS 14 or later, build 9.

## Main Features

- Edit existing Note Station HTML documents with rich-text formatting without converting them to Markdown. Supports fonts, colors, lists, links, checkboxes, tables, images, and undo.
- Markdown source, split preview, and reading modes; offline Mermaid and KaTeX; image pasting; and file import and export.
- Synchronize equations as ordinary PNG attachments while preserving the exact Markdown source, TeX delimiters, backslashes in code, and line breaks.
- Automatic uploads, offline storage of bodies and attachments, search, tags and favorites, and management of notebooks, trash, and revision history.
- Keychain storage for passwords and device tokens, OTP, automatic login, and connection recovery.
- Distinguish conflicts from lost responses and prevent upload completion from overwriting subsequent edits or undo operations.

## Installation Files

- `SynologyMarkdownNote-1.0.0-arm64.dmg`: installation image for copying the app to Applications.
- `SynologyMarkdownNote-1.0.0-arm64.zip`: ZIP of the same app bundle.
- `SHA256SUMS`, `manifest.json`, `distribution.ko.md`: checksums, build information, and installation instructions.

Quit the existing app normally before replacing it. There is no need to delete note data or account settings. Release packages do not include personal notes, accounts, passwords, or signing private keys.

## Validation and Limitations

Validated 223 regression tests / 23 suites, actual WebKit formatting and equation PNG rendering, synthetic NAS round trips, SQLite preservation, and app relaunch. Release packages are checked for DMG integrity, read-only mounting, ZIP extraction, nested signatures, and checksums.

Signed with a local development certificate; no Developer ID signing or Apple notarization. Installation on another Mac, Intel/universal support, current round trips through a real NAS web interface, and simultaneous editing on multiple Macs require separate validation. Encrypted note editing, QuickConnect ID discovery, and bypassing certificate validation are not supported. Structural changes to merged tables are blocked, and unsupported widgets retain their original content.
