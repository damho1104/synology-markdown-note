# Synology Markdown Note 1.2.14 (Build 25)

**English** | [한국어](1.2.14.ko.md)

Refines the names and placement of diagnostic export controls in Settings → Diagnostics. Existing diagnostic material and log ZIP export features are retained.

## Changes

- Rename the “Diagnostic material for the developer” section to the simpler “Export”.
- Arrange sections as “Log rotation and retention → Diagnostic logs → Export” so that related tasks appear consecutively.
- Move the “Export diagnostics…” and “Export logs only…” buttons above their descriptions.
- Continue displaying guidance on DB status and integrity checks, included log content, exclusion of personal information, and identifier anonymization.

## Validation

- All 324 Swift regression tests (35 suites) passed, including 4 diagnostic export tests.
- All 100 Python CLI tests passed (`uv run --locked pytest -q tests`).
- Release DMG and ZIP files, app and Credential Helper signatures, and checksums are validated during release packaging.

## Distribution Scope

Distributes app DMG and ZIP files for macOS 14 or later on Apple Silicon arm64 and the CLI for Ubuntu 22.04/24.04 amd64 and macOS arm64. The app is signed with the existing local development certificate; Apple Developer ID signing and notarization are not included. This change does not affect data in the installed app or on the production NAS.
