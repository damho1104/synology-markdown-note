## 보안 업데이트

- **CLI:** HTTPS 연결에 쓰는 인증서 번들을 `certifi 2026.10.23`으로 갱신했습니다. 손상된 중간 CA 키를 차단하는 Python `3.13.18`을 릴리스 빌드에 고정하고, 빌드용 `setuptools`도 `84.2.1`로 올렸습니다. [certifi 보안 권고](https://github.com/advisories/GHSA-6q48-6c7w-9gw2) · [Python 보안 릴리스](https://www.python.org/downloads/release/python-31318/)
- **웹 서버:** 임시 첨부와 저장된 자격 증명의 암호화에 사용하는 `cryptography`를 `50.0.2`로 갱신했습니다. 이전 웹 이미지와 새 이미지가 서로 암호화한 테스트 데이터를 amd64와 arm64 모두에서 복호화하는 것을 확인했습니다. [cryptography 보안 권고](https://github.com/advisories/GHSA-g6cj-pr64-35w5)
- **macOS 앱:** 오프라인 다이어그램 미리보기에 사용하는 Mermaid를 `12.3.0`으로 갱신했습니다. 번들에 포함된 DOMPurify는 `3.4.17`입니다. [DOMPurify 보안 권고](https://github.com/advisories/GHSA-55q2-fjhq-7xh7)

기존 CLI 실행 파일과 macOS 앱을 새 빌드로 교체하세요. Docker Compose로 웹을 운영한다면 `1.2.24` 이미지를 받도록 설정한 뒤 컨테이너를 다시 생성하세요. 기존 웹 데이터 볼륨을 그대로 사용하면 됩니다.

이 릴리스는 앱이 번들로 제공하는 의존성을 갱신합니다. Debian 기반 이미지의 시스템 패키지와 외부 리버스 프록시는 각 배포 환경에서 별도로 관리해야 합니다.

## Security update

- **CLI:** Updated the CA bundle used for HTTPS to `certifi 2026.10.23`. Release builds now use Python `3.13.18`, which blocks the compromised intermediate CA keys, and build tooling uses `setuptools 84.2.1`. [certifi advisory](https://github.com/advisories/GHSA-6q48-6c7w-9gw2) · [Python security release](https://www.python.org/downloads/release/python-31318/)
- **Web server:** Updated `cryptography`, which protects staged attachments and stored credentials, to `50.0.2`. The previous and updated web images could decrypt each other's test data on both amd64 and arm64. [cryptography advisory](https://github.com/advisories/GHSA-g6cj-pr64-35w5)
- **macOS app:** Updated the offline diagram preview to Mermaid `12.3.0`, which bundles DOMPurify `3.4.17`. [DOMPurify advisory](https://github.com/advisories/GHSA-55q2-fjhq-7xh7)

Replace existing CLI binaries and macOS apps with the new builds. For Docker Compose deployments, select the `1.2.24` image and recreate the web container with its existing data volume.

This release updates bundled application dependencies. Debian base image packages and external reverse proxies have their own security update processes.
