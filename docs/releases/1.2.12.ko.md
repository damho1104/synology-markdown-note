# Synology Markdown Note 1.2.12 (빌드 23)

설정에서 개발자에게 전달할 진단 자료를 내보내고, 로그 회전·보관 정책을 조절할 수 있습니다. 오른쪽 노트 정보 패널을 열거나 폭을 바꿀 때 내용이 잘리던 문제도 수정했습니다.

## 변경 사항

- **진단 자료 내보내기**: 현재 계정의 DB 상태 보고서와 현재·이전 로그를 ZIP으로 저장합니다. **로그만 내보내기**도 제공합니다. 저장 위치는 사용자가 선택하며 자동 전송하지 않습니다.
- DB 보고서는 SQLite·스키마 버전, 무결성 검사 결과, 페이지·테이블별 행 개수, 동기화 상태별 개수, FTS 고아·누락·불일치 행 개수, 백업 개수·총용량만 포함합니다. 원본 DB를 복사하지 않고 실행 중인 저장소의 읽기 트랜잭션으로 조회합니다.
- 로그는 허용된 이벤트·필드·값으로 다시 구성하고 계정·노트·메모장 식별자를 ZIP별 별칭으로 바꿉니다. 대응표, 노트 제목·본문·수정 이력 내용, 첨부파일, NAS 주소·사용자 이름·경로·Keychain 정보, macOS 확장 속성은 포함하지 않습니다. 작업 시각·오류 코드·개수·용량은 진단을 위해 포함합니다.
- DB 열기·무결성 검사·검색 인덱스 정리·공간 회수·백업·복구·복구 되돌리기의 시작·완료·실패와 소요 시간 및 집계값을 기록합니다. 오류 설명 원문은 기록하지 않습니다.
- **로그 회전·보관**: 파일당 용량(1·2·5·10 MiB), 현재 파일을 포함한 개수(1~20개), 전체 용량(1~64 MiB)을 각각 설정합니다. 기본값은 2 MiB·4개·합계 8 MiB입니다. 기록 전에 한도를 검사하며 초과 전에 회전하고 오래된 파일부터 정리합니다.
- 보관 정책은 재시작 후 유지하며 변경·시작 시 기존 로그에도 적용합니다. 파일을 줄일 때는 최근의 완전한 JSON 줄만 유지하고, ‘지금 로그 회전’으로 새 파일을 준비할 수 있습니다. 내보내기는 변경한 보관 개수만큼의 로그를 포함합니다.
- **노트 정보 패널 잘림 수정**: 좁은 오른쪽 패널 안에서 더 넓은 최소 너비를 요구하던 grouped Form을 패널 폭에 맞는 스크롤 섹션으로 변경했습니다. 태그·첨부파일·그래프·수정 이력 기능을 유지합니다.
- 메모장 삭제 회귀 테스트는 예약 업로드의 종료를 기다려 삭제 시점의 동기화 작업과 경합하지 않게 했습니다. 자동 재연결 테스트도 새로고침·업로드 루프와 재예약된 업로드 작업까지 종료를 기다린 뒤 세션 만료를 주입합니다.

## 검증

- Swift 전체 317개 테스트 / 34개 스위트, Python CLI 100개 테스트.
- 진단 ZIP의 실제 압축 해제, 개인정보 제외·식별자 익명화, macOS 숨은 메타데이터 제외, 로그 동시 기록, 회전·개수·용량 한도 및 설정 저장 검증.
- 노트 정보 패널은 260·300·360·520pt 및 다시 260pt로 변경하는 레이아웃 테스트를 통과했습니다. 수정 전 같은 테스트에서 508pt 최소 너비로 실패하는 것을 확인했습니다.
- 격리된 개발 앱에서 진단 ZIP 저장, 로그 한도 설정·수동 회전, 노트 정보 패널과 첨부파일·수정 이력 표시를 확인했습니다.

## 배포 및 범위

macOS 14+ Apple Silicon DMG·ZIP, Ubuntu 22.04/24.04 amd64 및 macOS arm64 CLI를 함께 배포합니다. 앱은 기존 로컬 인증서로 서명하며 Apple Developer ID 서명·공증은 포함하지 않습니다. OSLog의 보관은 macOS가 관리하며 위 용량 제한은 앱의 로컬 JSONL 로그에 적용합니다.

진단 ZIP은 노트 복원용 백업이 아닙니다. SQLite 자동 백업은 기존처럼 첨부파일 원본·Keychain 정보를 포함하지 않습니다. 이번 릴리스 게시는 설치된 앱 교체나 운영 DB·NAS 수정 작업을 수행하지 않습니다.
