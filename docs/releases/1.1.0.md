# Synology Markdown Note 1.1.0

**English** | [한국어](1.1.0.ko.md)

Apple Silicon (arm64), macOS 14 or later, build 10.

## New Features

- SQLite FTS5 full-text search, advanced search combining title, tag, notebook, and date criteria, and saved search criteria (smart notebooks).
- Click navigation for internal Markdown note links, a backlink list for the current note, preservation of resolved note links after renaming, and safe handling of duplicate titles.
- Full and local graph views: explore connections 1–3 levels deep, open notes, filter by search, tags, and notebooks, zoom, and pan by dragging.
- NAS write compatibility checks create or reuse a separate test notebook and automatically collapse the results area when checks finish.

## Installation Files

- `SynologyMarkdownNote-1.1.0-arm64.dmg`: app installation image.
- `SynologyMarkdownNote-1.1.0-arm64.zip`: ZIP of the same app bundle.
- `SHA256SUMS`, `manifest.json`, `distribution.ko.md`: integrity checks, build information, and installation instructions.

Quit the existing app normally before replacing it. There is no need to delete local notes, login information, or settings.

## Validation and Limitations

Distribution is based on 243 regression tests / 25 suites, a Release app build, read-only DMG mounting, ZIP extraction, nested signature verification, and checksum verification. Current round trips with a real NAS, simultaneous editing on multiple Macs, installation on another Mac, and all visual graph interactions require separate checks.

Signed with a local development certificate; no Developer ID signing or Apple notarization. Intel/universal builds are not provided.
