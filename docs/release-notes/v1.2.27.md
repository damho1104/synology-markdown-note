## 웹 편집 툴바와 모바일 탐색

- **기존 메모를 저장된 형식으로 편집합니다.** Note Station의 서식 도구로 작성된 메모를 열면 제목 아래에 아이콘 툴바가 표시됩니다. 문단 스타일, 글꼴·크기·색, 정렬, 목록·체크리스트, 링크, 표, 첨부를 사용할 수 있습니다. 새 메모는 Markdown으로 만들며, 기존 Markdown 메모는 원문·분할·읽기 보기를 제공합니다.
- **편집과 저장이 이어집니다.** 이미지가 포함된 메모에서도 자동 저장 후 커서 위치와 키보드 실행 취소가 유지됩니다. 본문과 첨부를 함께 저장한 뒤 본문 편집을 되돌려도 첨부파일은 유지됩니다. 저장 결과가 불확실할 때는 NAS 확인본을 검토하고, 편집 위치를 확인할 수 있으면 보관한 편집본으로 이어서 작업할 수 있습니다.
- **모바일에서는 한 단계씩 이동합니다.** 책장, 메모장, 메모 목록, 편집 화면을 차례로 엽니다. 상단 화살표로 한 단계 위로 이동하고, 편집 중에는 기본 도구를 한 줄로 사용하다가 더보기에서 추가 도구를 열 수 있습니다.

Docker Compose를 사용하는 경우 기존 데이터 볼륨을 유지하고 `1.2.27` 웹 이미지로 컨테이너를 다시 생성하세요. 웹, macOS, CLI의 공통 버전은 `1.2.27`입니다.

## Web editing toolbar and mobile navigation

- **Edit existing notes in their saved format.** Notes created with Note Station’s formatting tools open with an icon toolbar below the title. It supports paragraph styles, fonts, sizes, colors, alignment, lists, checklists, links, tables, and attachments. New notes are created as Markdown, and existing Markdown notes offer source, split, and reading views.
- **Keep editing after a save.** Autosave preserves the caret and keyboard undo in notes containing images. Undoing a body edit after saving it together with an attachment keeps the file. If a save result is uncertain, review the NAS copy and resume the held draft when its edit positions can be verified.
- **Navigate one screen at a time on mobile.** Open a bookshelf, then a notebook, then a note from its list to reach the editor. The header arrow goes up one level. The editing toolbar keeps common actions in one row and reveals additional tools with More.

For Docker Compose, keep the existing data volume and recreate the web container with the `1.2.27` image. The web, macOS, and CLI clients share version `1.2.27`.
