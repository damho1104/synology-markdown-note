# Synology Markdown Note 1.2.0

[English](1.2.0.md) | **한국어**

Apple Silicon(arm64), macOS 14 이상, 빌드 11.

## 새로운 기능

- Synology Note Station의 책장(Stack)을 메모장과 함께 표시합니다. 책장 생성·이름 변경·삭제, 펼치기·접기, 책장별 노트 필터링을 지원합니다.
- 하나 또는 여러 메모장을 책장에 넣거나 책장 밖으로 이동할 수 있습니다. 드래그 앤 드롭과 컨텍스트 메뉴를 지원합니다.
- 책장 이름 변경 후 현재 선택을 유지하고, 책장 삭제 시 소속만 해제해 메모장 및 노트 본문을 보존합니다.
- 공식 Note Station Client 3.0.0-883에서 확인한 Notebook/Stack NAS API를 사용합니다. 네트워크 응답 유실 시 서버 목록을 재조회하여 중복 변경 요청을 방지합니다.
- 계정별 로컬 데이터 분리와 이전 SQLite 메모장 정보의 호환성을 유지하고, 책장 작업 중 자동 업로드와의 경합을 방지합니다.

기존 1.1.0의 FTS5 고급 검색·스마트 메모장·노트 링크·백링크·그래프와 1.0.0의 HTML 편집·Markdown·수식 PNG 동기화를 유지합니다.

## 설치 파일

- `SynologyMarkdownNote-1.2.0-arm64.dmg`: 앱 설치 이미지.
- `SynologyMarkdownNote-1.2.0-arm64.zip`: 같은 앱 번들의 ZIP.
- `SHA256SUMS`, `manifest.json`, `distribution.ko.md`: 무결성·빌드 정보·설치 안내.

기존 앱을 정상 종료한 뒤 교체하면 됩니다. 로컬 노트·로그인·설정을 삭제하거나 초기화할 필요가 없습니다.

## 검증과 제한

253개 테스트 / 26개 스위트로 책장 API 호출 형식, 재조회·응답 유실, 계정별 소속, 노트 보존과 회귀 동작을 검증했습니다. Release 빌드, DMG 읽기 전용 마운트, ZIP 압축 해제, 중첩 서명, 체크섬을 배포 시 검사합니다.

공식 클라이언트의 내부 API와 합성 NAS 응답을 기준으로 책장을 구현했습니다. 실제 NAS의 책장 생성·변경·삭제, 공식 클라이언트와의 상호운용성, 여러 Mac 동시 편집 및 다른 Mac 설치는 아직 재검증하지 않았습니다.

로컬 개발 인증서로 서명했으며 Developer ID 서명과 Apple 공증은 받지 않았습니다. Intel/universal 빌드는 제공하지 않습니다.
