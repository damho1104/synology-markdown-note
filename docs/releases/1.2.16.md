# Synology Markdown Note 1.2.16 (Build 27)

**English** | [한국어](1.2.16.ko.md)

Improves unwanted scroll position movement when editing long Markdown documents after scrolling.

## Changes

- Reduce repeated application of Markdown formatting to the entire document while typing. Skip reapplication when text and font size are unchanged.
- Compute formatting in a separate attributed string and compare it with existing formatting, updating only ranges that actually changed.
- Preserve attachment and original-content block token attributes, and restore Markdown highlighting after Undo/Redo.
- Retain the existing behavior that suppresses formatting changes during Korean input method composition.

## Validation

- Added a regression test that checks viewport and cursor positions during continuous typing in a scrolled 240-line document.
- Added a regression test that checks formatting restoration after deleting Markdown syntax and undoing the deletion.
- All 329 Swift regression tests (36 suites) and 100 CLI tests passed on the release source.
- Package signatures, checksums, and platform-specific builds were validated separately during the existing release preparation process. Packages for GitHub distribution require revalidation.
- Does not install the app currently in use or modify NAS data.

## Distribution Scope

Distributes app DMG and ZIP files for macOS 14 or later on Apple Silicon arm64 and the CLI for Ubuntu 22.04/24.04 amd64 and macOS arm64. The app is signed with a local development certificate; Apple Developer ID signing and notarization are not included.
