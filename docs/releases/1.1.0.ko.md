# Synology Markdown Note 1.1.0

Apple Silicon(arm64), macOS 14 이상, 빌드 10.

## 새로운 기능

- SQLite FTS5 전문 검색, 제목·태그·메모장·날짜 조건을 결합한 고급 검색과 저장된 검색 조건(스마트 메모장).
- Markdown 내부 노트 링크의 클릭 이동, 현재 노트의 백링크 목록, 이름 변경 후 확정된 노트 연결 유지 및 중복 제목 안전 처리.
- 전체·로컬 그래프 뷰: 연결 1~3단계 탐색, 노트 열기, 검색·태그·메모장 필터, 확대·축소·드래그 이동.
- NAS 쓰기 호환성 검사는 별도 검사 메모장을 생성·재사용하고, 검사 완료 시 결과 영역을 자동으로 접음.

## 설치 파일

- `SynologyMarkdownNote-1.1.0-arm64.dmg`: 앱 설치 이미지.
- `SynologyMarkdownNote-1.1.0-arm64.zip`: 같은 앱 번들의 ZIP.
- `SHA256SUMS`, `manifest.json`, `distribution.ko.md`: 무결성·빌드 정보·설치 안내.

기존 앱을 정상 종료한 뒤 교체하면 된다. 로컬 노트·로그인·설정은 삭제할 필요가 없다.

## 검증과 제한

전체 회귀 검사 243개 / 25개 스위트, Release 앱 빌드, 읽기 전용 DMG 마운트, ZIP 압축 해제, 중첩 서명 및 체크섬 검증을 기준으로 배포한다. 실제 NAS의 최신 왕복·여러 Mac 동시 편집, 다른 Mac 설치와 그래프의 모든 시각적 상호작용은 별도 확인이 필요하다.

로컬 개발 인증서로 서명했으며 Developer ID 서명과 Apple 공증은 받지 않았다. Intel/universal 빌드는 제공하지 않는다.
