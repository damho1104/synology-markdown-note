## 웹 클라이언트 기능 확장

- **메모장·책장 삭제**: 사이드바에서 메모장이나 책장을 우클릭해 삭제할 수 있습니다. 메모장을 삭제하면 포함된 노트가 휴지통으로 이동하고, 책장 삭제는 분류만 해제해 메모장과 노트는 그대로 남습니다.
- **본문 검색**: 전역 검색에서 제목·미리보기·태그와 함께 색인된 노트 본문을 찾을 수 있습니다. 잠긴 노트의 본문은 색인하지 않으며, 본문 색인은 링크 색인과 같은 NAS 조회를 재사용해 진행률을 표시합니다. 검색 인덱스는 NAS·계정별로 구분해 서버에 암호화하여 보관합니다.
- **Markdown 가져오기**: 메모장을 선택하고 상단 **Markdown 가져오기**로 UTF-8 `.md`·`.markdown` 파일을 고르면 파일마다 새 노트를 만듭니다.
- **원본 HTML 서식·표 편집**: 기존 HTML 노트에서 텍스트 한 구간을 선택해 굵게·기울임·밑줄·취소선을 적용하고, 병합 셀이 없는 표에서 행과 열을 추가·삭제할 수 있습니다. 변경 대상 밖의 원본 HTML은 그대로 보존합니다.
- **미사용 첨부 제거**: 노트 정보 패널의 첨부파일 옆 휴지통 버튼으로 NAS에 저장된 파일을 제거할 수 있습니다. 본문에서 사용하는 파일은 본문 참조를 먼저 제거해야 합니다.
- **수정 이력 조회·복원**: 노트 정보의 **수정 이력 조회**에서 NAS가 목록에 표시하는 버전을 미리 보고 이전 버전으로 돌아갈 수 있습니다. 복원은 선택한 제목과 본문을 새 버전으로 저장하며, NAS의 현재 버전이 바뀌었는지 확인합니다. 현재 사용자 첨부파일은 유지합니다. 웹에서 저장한 내용은 최종 버전이 이력에 기록됩니다.

Docker Compose를 사용하는 경우 `1.2.26` 웹 이미지로 컨테이너를 다시 생성하세요. 기존 웹 데이터 볼륨을 그대로 사용하면 됩니다. 웹, macOS, CLI의 공통 버전은 `1.2.26`입니다.

## Web client feature expansion

- **Delete notebooks and bookshelves**: Right-click a notebook or bookshelf in the sidebar to delete it. Deleting a notebook moves its notes to the trash; deleting a bookshelf only clears the grouping and keeps notebooks and notes in place.
- **Body search**: Global search now covers indexed note bodies in addition to titles, previews, and tags. Locked note bodies are excluded from the index. Body indexing reuses the same NAS reads as link indexing and shows its progress. Search indexes are encrypted and stored per NAS account on the server.
- **Markdown import**: Select a notebook and use **Import Markdown** to pick UTF-8 `.md` or `.markdown` files; each file becomes a new note.
- **Original HTML formatting and table editing**: In an existing HTML note, select a run of text to apply bold, italic, underline, or strikethrough, and add or remove rows and columns in tables without merged cells. The original HTML outside the edited range is preserved.
- **Unused attachment removal**: Use the trash icon next to an attachment in the note information panel to remove the file stored on the NAS. Remove body references to a file before deleting it.
- **Revision history and restore**: Open **Revision history** in the note information panel to preview versions listed by the NAS and restore an earlier one. A restore saves the selected title and body as a new version and checks whether the current NAS version changed. Existing user attachments are kept. Completed web saves publish a listable version to the history.

For Docker Compose, recreate the web container with the `1.2.26` image and keep its existing data volume. The web, macOS, and CLI clients share version `1.2.26`.
