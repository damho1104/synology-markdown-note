## 웹 노트 목록의 Markdown 배지 수정

- 노트를 열기 전에도 웹 목록에서 Markdown 노트에 `MD` 배지가 표시됩니다. 처음 확인하는 노트의 배지는 백그라운드 확인이 끝나면 나타납니다.
- 확인한 형식은 웹 서버에 저장됩니다. 노트의 NAS 버전이 바뀌면 다음 목록 조회에서 형식을 다시 확인하므로 Markdown으로 변환한 노트에도 배지가 표시됩니다.
- 코드 블록이 들어 있거나 일반 `.md` 파일이 첨부된 HTML 노트의 배지 오표시를 수정했습니다.

Docker Compose를 사용하는 경우 `1.2.25` 웹 이미지로 컨테이너를 다시 생성하세요. 기존 웹 데이터 볼륨을 그대로 사용하면 됩니다.

## Markdown badges in the web note list

- Markdown notes now show an `MD` badge in the web list before you open them. For newly checked notes, the badge appears when the background check finishes.
- The web server caches the verified format. When the NAS note version changes, the format is checked again the next time the list loads, so notes converted to Markdown receive a badge.
- Fixed false badges on HTML notes that contain a code block or a regular `.md` attachment.

For Docker Compose, recreate the web container with the `1.2.25` image and keep its existing data volume.
