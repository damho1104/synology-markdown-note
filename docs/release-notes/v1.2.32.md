## 백그라운드 업로드와 마크다운 동기화

- macOS에서 로컬 메모장 이관이 확인 대기 중이어도, 대상이 확인된 메모와 첨부는 백그라운드에서 계속 전송됩니다. 업로드 중에도 다른 메모를 열고 편집할 수 있습니다.
- macOS 편집기와 설정에서 현재 업로드 진행률과 남은 대기 건수를 볼 수 있습니다. 자동으로 다시 확인하는 상태는 진행 상태로 표시합니다. 배치 전체가 중단되면 설정의 동기화 영역에서 오류를 확인할 수 있습니다.
- 새 메모의 생성 응답이 끊겼을 때, macOS는 NAS에 남은 임시 원본과 첨부가 이번 업로드와 일치하고 메모가 변경되지 않았음을 확인한 뒤 같은 메모에 게시를 이어갑니다.
- macOS와 웹은 다른 기기에서 마크다운 원본을 올리는 동안 **동기화 중**을 표시합니다. 원본이 올라오면 열린 메모를 자동으로 갱신합니다. macOS는 게시를 기다리는 동안 사용자 첨부 다운로드를 보류합니다.

## Background uploads and Markdown sync

- On macOS, notes and attachments with confirmed destinations continue uploading while a local notebook migration awaits confirmation. You can open and edit other notes during an upload.
- The macOS editor and Settings show upload progress and the number of pending uploads. Automatic checks appear as status updates. If an error stops the entire batch, its details appear in the Sync section of Settings.
- If the response to a new note creation is lost, macOS verifies that the staging source and attachments on the NAS match the upload and that the note is unchanged, then resumes publishing to the same note.
- Both macOS and the web display **Syncing** while another device publishes a Markdown source. The open note updates automatically after publication. macOS defers downloading user attachments while it waits.
