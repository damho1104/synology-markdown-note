## 웹 목록 자동 갱신

- 웹에서 NAS 메모장·메모 목록을 자동으로 갱신합니다. **설정 → 동기화 → 목록 갱신 주기**에서 변경할 수 있으며 기본값은 5분, 최솟값은 1분입니다.
- 탭을 숨기면 자동 조회가 중단됩니다. 탭으로 돌아왔을 때 갱신 주기가 지났으면 목록을 갱신합니다. 자동 조회는 유휴 세션 만료 시간을 연장하지 않습니다.
- 저장 요청을 보내기 전에 인증에 실패하면 편집본을 보존하고 다시 저장할 수 있습니다.

## Automatic library refresh on the web

- The web client automatically refreshes NAS notebook and note lists. Set the interval under **Settings → Sync → List refresh interval**. The default is 5 minutes and the minimum is 1 minute.
- Automatic reads pause when the tab is hidden. Returning to the tab refreshes the lists if the interval has elapsed. Automatic reads do not extend the idle session timeout.
- If authentication fails before a save is sent, the draft is preserved and you can retry the save.
