## 표시 언어와 NAS 연결 상태

- 웹의 **설정 → 표시 언어**에서 서버 기본값, 브라우저 언어, 영어 또는 한국어를 선택할 수 있습니다. 선택은 브라우저에 저장됩니다. 서버 기본값은 `WEB_DEFAULT_LANGUAGE`로 지정하며, 값을 생략하면 브라우저 선호 언어를 따릅니다.
- macOS의 **설정 → 일반 → 표시 언어**에서 시스템 기본값, 영어 또는 한국어를 선택할 수 있습니다. 앱을 다시 열면 적용됩니다. CLI의 도움말과 오류 메시지는 영어로 표시됩니다.
- 웹과 macOS의 왼쪽 사이드바 계정 영역에서 NAS 연결 상태를 확인할 수 있습니다. 서버 아이콘의 배지는 연결되면 초록색, 연결에 실패했거나 해제되면 빨간색입니다.
- 웹에서 언어를 바꾸면 열린 미리보기와 NAS 오류 메시지가 즉시 바뀝니다. 미리보기에서 펼쳐 둔 문서 정보는 그대로 열려 있고, 다른 탭에서 화면 모드를 바꿔도 저장한 언어는 유지됩니다.
- 새 메모는 표시 언어에 따라 `새 노트` 또는 `New Note`로 시작합니다. 언어를 바꿔도 기존 메모 제목과 메모장 이름은 유지됩니다.

## Display language and NAS connection status

- Under **Settings → Display language** on the web, choose the server default, browser language, English, or Korean. The choice is saved in that browser. The server default comes from `WEB_DEFAULT_LANGUAGE`, which follows browser preferences when unset.
- On macOS, choose System Default, English, or Korean under **Settings → General → Display Language**. Reopen the app to apply the change. CLI help and error messages are in English.
- The account area at the bottom of the left sidebar shows the NAS connection status on the web and macOS. The server icon has a green badge when connected and a red badge when the connection fails or is disconnected.
- Changing the web display language updates the open preview and NAS errors immediately. Expanded document information stays open, and changing the appearance in another tab preserves the saved language.
- New notes start with `새 노트` or `New Note` according to the display language. Existing note titles and notebook names are preserved when the language changes.
