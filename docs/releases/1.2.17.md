# Synology Markdown Note 1.2.17 (Build 28)

**English** | [한국어](1.2.17.ko.md)

Reduces the wait for the interface to respond when creating or saving a new note and opening NAS notes.

## Changes

- Update the editing session and list immediately after saving a new note locally. Perform full smart search and graph recalculation in the background after saving, coalescing consecutive changes into updates.
- After saving a note, update the changed title, list, and graph node first, followed by smart notebook results and link relationships.
- Avoid reading note summaries twice during full list refreshes. Prevent older refresh results from overwriting newer local changes or another account's interface.
- Complete note selection without waiting for the NAS body download. Show the body loading state and prevent duplicate downloads within the same editing session.
- Apply favorite and trash changes after the body finishes downloading to prevent saving empty bodies and incorrect synchronization conflicts. Defer direct editing while the body is unavailable.
- Wait for an already-running body download together, and clean up failed downloads so that subsequent operations can retry.
- Retain existing procedures that protect local saves, revision history, the transfer queue, synchronization conflicts, and uncertain write results.

## Validation

- Validate immediate display of new notes, preservation of local saves, history, and the transfer queue, smart search and graph updates after saving, and protection during account switching.
- Validate that note selection completes first even with a NAS response held, without duplicate body requests.
- During the existing release preparation process, all 335 Swift regression tests (36 suites) and 100 CLI tests passed. Binaries for GitHub distribution, signatures, and checksums require separate validation.
- In a local test with 1,200 notes and 2 smart searches, new note creation took approximately 2.3ms. This does not represent actual NAS response times or perceived speed in every environment.
- Does not replace the actually installed app or modify user NAS data.

## Distribution Scope

Distributes app DMG and ZIP files for macOS 14 or later on Apple Silicon arm64 and the CLI for Ubuntu 22.04/24.04 amd64 and macOS arm64. The app is signed with a local development certificate; Apple Developer ID signing and notarization are not included.
