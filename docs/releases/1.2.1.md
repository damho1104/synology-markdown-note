# Synology Markdown Note 1.2.1

**English** | [한국어](1.2.1.ko.md)

Apple Silicon (arm64), macOS 14 or later, build 12.

## Fixes

- When creating, moving, renaming, or deleting a stack, wait up to 30 seconds for an automatic upload or NAS refresh already in progress to finish before proceeding. Schedule stack operations so that new automatic synchronization jobs cannot intervene once the stack operation starts.
- If the connection or account changes while waiting, or the operation is canceled, exit without starting a NAS write.
- Display failure messages directly in the stack creation window. Diagnostic logs record only the start, completion, and failure stages of stack operations and safe error codes.
- Preserve notes and notebooks, existing login and Keychain credentials, and the data storage format.

## Installation Files

- `SynologyMarkdownNote-1.2.1-arm64.dmg`: app installation image.
- `SynologyMarkdownNote-1.2.1-arm64.zip`: ZIP of the same app bundle.
- `SHA256SUMS`, `manifest.json`, `distribution.ko.md`: integrity checks, build information, and installation instructions.

Quit the existing app normally and replace only the app bundle. Do not reset local notes or account settings.

## Validation Scope

Synthetic NAS regression checks now cover races with automatic refreshes and uploads, connection changes, cancellation, simultaneous stack creation, and exclusion of sensitive information from error logs. Successful stack creation and moves on a real NAS require separate real-world validation.

The arm64 app is signed with a local development certificate. Apple notarization and Intel builds are not provided.
