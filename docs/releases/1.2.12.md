# Synology Markdown Note 1.2.12 (Build 23)

**English** | [한국어](1.2.12.ko.md)

Export diagnostic material for the developer and adjust log rotation and retention policies in Settings. Also fixes clipped content when opening or resizing the right-hand note information panel.

## Changes

- **Export diagnostics**: save the current account's DB status report and current and previous logs as a ZIP. **Export logs only** is also available. The user chooses the save location; nothing is sent automatically.
- The DB report includes only SQLite and schema versions, integrity check results, page counts and per-table row counts, counts by synchronization status, counts of orphaned, missing, and mismatched FTS rows, and backup counts and total size. It queries a read transaction in the running repository rather than copying the original DB.
- Logs are reconstructed from allowed events, fields, and values, and account, note, and notebook identifiers are replaced with aliases unique to each ZIP. The alias mapping, note titles, bodies and revision history content, attachments, NAS addresses, usernames, paths, Keychain information, and macOS extended attributes are excluded. Operation times, error codes, counts, and sizes are included for diagnosis.
- Record start, completion, and failure events, durations, and aggregate values for DB opening, integrity checks, search index cleanup, space reclamation, backups, recovery, and recovery rollback. Raw error descriptions are not recorded.
- **Log rotation and retention**: configure per-file size (1, 2, 5, or 10 MiB), file count including the current file (1–20), and total size (1–64 MiB) separately. Defaults are 2 MiB, 4 files, and 8 MiB total. Limits are checked before writing; files rotate before exceeding them, and the oldest files are removed first.
- Retention policies persist after restart and apply to existing logs at startup and when changed. When shrinking a file, keep only the most recent complete JSON lines; “Rotate logs now” prepares a new file. Exports include logs up to the configured retention count.
- **Fix clipped note information panel**: replace the grouped Form, which required a minimum width wider than the narrow right-hand panel, with scrollable sections that fit the panel width. Preserve tags, attachments, graphs, and revision history.
- Notebook deletion regression tests wait for scheduled uploads to end to avoid races with synchronization at deletion time. Automatic reconnection tests also wait for refresh and upload loops and rescheduled upload jobs to finish before injecting session expiration.

## Validation

- Full Swift suite: 317 tests / 34 suites; Python CLI: 100 tests.
- Validated actual diagnostic ZIP extraction, exclusion of personal information and anonymization of identifiers, exclusion of hidden macOS metadata, concurrent log writing, rotation and file-count and size limits, and saving settings.
- The note information panel passed layout tests at 260, 300, 360, and 520pt and back to 260pt. Before the fix, the same test failed with a minimum width of 508pt.
- Confirmed diagnostic ZIP saving, log limit configuration and manual rotation, and display of the note information panel, attachments, and revision history in an isolated development app.

## Distribution and Scope

Distributes macOS 14+ Apple Silicon DMG and ZIP files, alongside the CLI for Ubuntu 22.04/24.04 amd64 and macOS arm64. The app is signed with the existing local certificate; Apple Developer ID signing and notarization are not included. macOS manages OSLog retention; the size limits above apply to the app's local JSONL logs.

Diagnostic ZIPs are not backups for restoring notes. As before, automatic SQLite backups do not include original attachments or Keychain information. Publishing this release does not replace the installed app or modify the production DB or NAS.
