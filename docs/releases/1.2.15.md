# Synology Markdown Note 1.2.15 (Build 26)

**English** | [한국어](1.2.15.ko.md)

Improves the readability and placement of the note link autocomplete popup that appears when typing `[[` in the Markdown editor.

## Changes

- Apply an opaque system background color, border, and shadow to the autocomplete list. Both light and dark modes are supported.
- Prefer placing the popup below and to the right of the editing cursor, adjusting its position to fit on screen when space is limited.
- Update the position when scrolling or resizing the window, and hide the list when the cursor moves outside the editor's visible area.
- Adjust popup height to the number of search results while retaining existing link search window behavior.

## Validation

- In the previous session, all 327 Swift regression tests (35 suites) passed, including tests for popup placement, screen edges, actual editor rendering, scrolling, and background opacity.
- Rendered and inspected synthetic test editor screens as PNGs for both light and dark themes.
- Swift and CLI tests, package signatures, and checksums were validated separately during the existing release preparation process. Packages for GitHub distribution require revalidation.
- The actual behavior of the installed production app and NAS data was neither changed nor validated.

## Distribution Scope

Distributes app DMG and ZIP files for macOS 14 or later on Apple Silicon arm64 and the CLI for Ubuntu 22.04/24.04 amd64 and macOS arm64. The app is signed with the existing local development certificate; Apple Developer ID signing and notarization are not included.
