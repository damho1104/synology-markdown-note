# 웹·macOS 앱·CLI 언어 지원 설계

웹과 macOS 앱에 한국어와 영어를 지원한다. CLI의 사용자 안내는 항상 영어로 표시한다.

## 언어 선택

| 클라이언트 | 동작 |
| --- | --- |
| 웹 | 배포 환경변수 `WEB_DEFAULT_LANGUAGE`로 `auto`, `en`, `ko` 중 하나를 선택한다. 미설정 시 `auto`다. |
| macOS 앱 | 앱 설정에서 시스템 설정 따르기, English, 한국어 중 하나를 선택한다. 기본값은 시스템 설정 따르기다. |
| CLI | 실행 환경의 로캘과 관계없이 영어를 사용한다. |

웹에서 `auto`는 접속한 브라우저의 선호 언어 목록에서 첫 번째로 지원되는 언어를 사용한다. 영어와 한국어의 지역 변형을 포함하고, 지원하는 언어가 없으면 영어를 사용한다. `en`과 `ko`는 해당 웹 인스턴스의 UI를 각각 영어와 한국어로 고정한다. 운영자는 같은 Docker 이미지에서 컨테이너 런타임 환경변수로 모드를 바꿀 수 있다. 로그인 화면부터 같은 규칙을 적용하고, 선택한 언어를 HTML의 `lang`에 반영한다.

브라우저 자동 선택은 방문자별 언어를 제공한다. 배포 인스턴스의 언어를 고정하면 관리자가 접속자 공통 언어를 정할 수 있다.

macOS 앱에서 시스템 설정을 따르는 경우 macOS의 선호 언어와 앱별 언어 설정을 읽고, 지원 언어를 선택할 수 없으면 영어를 사용한다. English와 한국어는 이 앱의 UI 언어를 고정한다. 선택값은 앱 설정에 저장하고 다음 실행부터 적용한다. 설정 화면에서 다시 열 때 적용된다고 안내한다.

## 번역 범위와 호환성

- 웹과 macOS의 메뉴, 설정, 편집기, 대화상자, 상태·오류 안내, 접근성 라벨을 번역한다. 사용자가 보는 날짜와 숫자 표시에도 선택한 로캘을 적용한다.
- CLI의 도움말, 입력 프롬프트, 상태·오류 안내, JSON의 `error.message`를 영어로 통일한다. 기존 명령·옵션, JSON 키와 응답 구조, 오류 코드, 종료 코드를 보존한다. 오류 메시지 문구를 비교하는 기존 스크립트에는 영향이 있다.
- 이미 저장된 메모장 이름, 메모 제목, 본문, 태그와 파일명은 원문으로 표시한다. 언어 전환으로 이름이나 제목을 변경하지 않는다. 새로 만드는 항목에 앱 기본 이름이 필요한 경우에는 생성 시점의 언어를 적용한다.
- 웹과 macOS에서 새 메모의 제목란은 한국어 `새 노트`, 영어 `New Note`로 시작한다. 웹은 제목이나 본문에 편집이 있을 때 NAS에 메모를 생성한다.

## NAS 상태 표시

웹과 macOS 앱의 오른쪽 아래에 NAS 상태 원을 표시한다. 연결이 확인되면 초록색, 연결 실패·해제 상태면 빨간색이다. 웹은 로그인 뒤 NAS 목록 조회로 연결을 확인하고 로그아웃 상태에서도 표시를 유지한다. macOS 앱은 기존 연결 상태를 사용한다. 접근성 라벨은 선택한 언어로 연결 여부를 읽어 준다.

## 완료 기준

- 웹에서 영어·한국어·미지원 언어가 우선인 브라우저로 자동 선택을 확인하고, `en`과 `ko`가 브라우저 선호 언어와 관계없이 적용되는지 확인한다. Compose 환경변수를 바꿔 같은 이미지에서 두 언어를 표시할 수 있는지 확인한다.
- 패키징한 macOS 앱을 영어와 한국어로 각각 실행해 메뉴, 로그인·설정, 편집기, 오류 안내를 확인한다. 앱 설정의 명시 선택이 재실행 후 적용되는지, 시스템 설정으로 돌리면 macOS의 언어 설정을 다시 따르는지, 지원 언어가 없으면 영어가 적용되는지 확인한다.
- CLI를 서로 다른 로캘에서 실행해 도움말과 오류가 영어로 표시되고 JSON 구조와 종료 코드가 유지되는지 확인한다.
