# Web/macOS 정렬 구현 기록

[English](2026-11-16-web-macos-alignment.md) | **한국어**

목표: 별도의 웹 디자인 대신 기존 macOS LibraryView/EditorView와 공개된 스크린샷을 따른다. 이미 승인된 웹 클라이언트 구현을 이어가는 작업이다.

참조: Sources/SynologyNote/Views/LibraryView.swift, EditorView.swift, Stores/EditorSession.swift, Sources/NoteCore/NoteListSort.swift, docs/images/markdown-split-preview.png 및 기존 웹 클라이언트 설계.

- [x] 검증된 브라우저 origin을 기준으로 HTTP/HTTPS 쿠키 속성을 자동 선택한다. 교차 출처 거부와 명시적인 기존 재정의 설정을 유지한다. 일반 Compose 설정에서 두 변수를 제거한다.
- [x] Mac의 사이드바/목록/편집기 비율, 중첩된 책장 펼치기, 책장에 속하지 않은 메모장, 태그와 휴지통 필터, 시스템 라이트/다크 색상 및 인스펙터를 사용한다.
- [x] 수정일 대체 기준을 포함해 제목/생성일/수정일 정렬과 방향을 일치시키고 환경설정을 영속 저장한다.
- [x] CodeMirror Markdown, 로컬 Mermaid 손그림 스타일 SVG 및 KaTeX로 원문/분할/읽기 모드를 제공한다. 샌드박스 미리보기는 노트 스크립트를 차단하고 nonce로 보호된 내부 링크 브리지만 허용한다.
- [x] 바이트 호환 v1-v3 원문 계약을 디코딩하고 본문/원문 지문을 검사하며 기존 원문 바이트와 불투명 블록을 보존한다.
- [x] 원문을 임시 저장하고 본문을 쓴 다음 충돌 검사와 첨부 보존을 거쳐 검증된 최종 원문을 게시한다. 결과가 불확실한 쓰기 예약은 재시도 없이 유지한다.
- [x] 응답 수신이 유실되는 모든 단계와 커밋된 Mac/CLI fixture에 대한 모의 HTTP 테스트를 수행한다. 탐색, 정렬, 다이어그램 및 실제 HTTP 쿠키를 실제 브라우저에서 검사한다.
- [ ] 실제 NAS 왕복 검증(사용자의 테스트 환경이 필요하며 임의의 실제 NAS 쓰기는 수행하지 않음).

0.4.0에서 추가로 완료된 작업:
- [x] 암호화된 영속 예약, 충돌 검사 및 정확한 재조회 검증을 갖춘 메타데이터와 라이브러리 라우트: 즐겨찾기, 태그, 휴지통/복원, 노트 이동, 메모장 생성/이름 변경/그룹 지정, 책장 생성/이름 변경. 영구 삭제는 제공하지 않는다.
- [x] 검증된 실제 링크 기반 그래프/백링크, 중복 문서 ID 보호, 내부 링크 삽입/해석 및 탐색.
- [x] 원문 오프셋을 이용한 기존 HTML 텍스트 패치로 알 수 없는 속성/첨부/불투명 페이로드를 보존한다. 정제된 동기식 텍스트 입력과 재조회 테스트를 포함한다.
- [x] 반복 가드, 실패 응답 및 동시 프런트엔드 읽기에 대한 세션 교체 회귀 테스트.

완료로 표시하지 않은 남은 차이점: 수식 PNG 재생성/업로드, 제한 없는 기존 HTML 서식 변경, 첨부 추가/삭제, 버전 기록 관리 및 오프라인 동기화. 실제 NAS 쓰기와 실물 Synology Container Manager 검증은 아직 수행하지 않았다.
