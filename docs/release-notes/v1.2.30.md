## 클라이언트 언어 설정

- 웹은 기본적으로 브라우저의 선호 언어를 따릅니다. 운영자는 `WEB_DEFAULT_LANGUAGE`를 `auto`, `en`, `ko`로 설정할 수 있습니다. 로그인, 초기 설정, 편집기 안내도 선택한 언어로 표시됩니다.
- macOS 앱은 **설정 → 일반 → 표시 언어**에서 시스템 기본값, English, 한국어를 선택할 수 있습니다. 변경 사항은 앱을 다시 열면 적용됩니다. CLI는 도움말과 오류를 영어로 표시합니다.
- 웹과 macOS의 새 메모에는 선택한 언어에 따라 `새 노트` 또는 `New Note`가 기본 제목으로 입력됩니다. 언어를 바꿔도 기존 메모와 메모장 이름은 유지됩니다.
- 웹과 macOS 오른쪽 아래의 NAS 상태 점은 연결 시 초록색, 연결 실패 또는 해제 시 빨간색으로 표시됩니다. 웹 서식 편집기에서 저장 중 제목을 지우면 늦게 도착한 저장 응답이 지운 제목을 되살리지 않습니다.

## Client language settings

- The web client follows the browser's preferred language by default. Operators can set `WEB_DEFAULT_LANGUAGE` to `auto`, `en`, or `ko`. Sign-in, first-time setup, and editor messages use the selected language.
- On macOS, choose System Default, English, or Korean under **Settings → General → Display Language**. Restart the app to apply the change. CLI help and errors are displayed in English.
- New notes in the web and macOS clients start with `새 노트` or `New Note` according to the display language. Changing the language preserves existing note and notebook names.
- The NAS indicator at the bottom right of the web and macOS clients shows green when connected and red on connection failure or disconnection. In the web formatted editor, clearing a title during a save keeps the field clear when the response arrives.
