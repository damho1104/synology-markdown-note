# 기존 Note Station 문서 편집

0.2.1 빌드 8부터 기존 HTML 문서를 열면 Markdown 변환 없이 서식 편집기가 표시된다. 본문·제목·태그·첨부 변경은 로컬 수정 이력에 먼저 저장하고 NAS에 자동 전송한다.

## 편집 기능

- 문단·제목·인용·코드, 글꼴·크기·글자색·강조색, 굵게·기울임·밑줄·취소선·첨자.
- 정렬·들여쓰기, 글머리·번호 목록, 체크리스트, 링크 추가·해제.
- 표 생성, 행·열 추가·삭제, 표 삭제. 병합된 표의 기존 내용은 보존하며 지원하지 않는 구조 조작은 수행하지 않는다.
- 파일·이미지 첨부, 이미지 붙여넣기·파일 드롭, 실행 취소·다시 실행.

문서를 열거나 선택만 했을 때는 원본 HTML 바이트를 유지한다. 실제 편집 시 HTML DOM으로 저장하며 기존 스타일·표·첨부 참조를 보존한다. WebKit 편집기는 계정·노트가 바뀐 뒤 도착한 오래된 변경을 반영하지 않고 한국어 조합 입력 중 새로고침을 미룬다.

## 원본·첨부 보존

앱에서 지원하지 않는 음성·동영상·iframe 등 위젯과 실행 요소는 비활성 원본 보존 표시로 대체한다. 편집 결과를 저장할 때 원래 HTML을 복원하며 위젯 자체를 새로 편집하는 기능은 제공하지 않는다. 기존 스타일은 편집기 영역에만 적용하고 사용자 스크립트·원격 자동 요청은 실행하지 않는다.

NAS의 ref-only 이미지와 다운로드 URL은 검증된 로컬 첨부로 표시한다. 편집기 표식·미리보기 URL이 저장 HTML에 섞이지 않도록 내보낼 때 원래 참조를 복원한다. 새 첨부는 동기화 때 NAS 참조로 바꾸며 해당 태그 외의 원본은 재직렬화하지 않는다. 본문이 참조하는 첨부는 제거할 수 없다.

웹 수정으로 Markdown 원문 지문이 달라진 노트도 이 편집기로 열어 최신 HTML을 유지한다. Markdown으로 전환하려면 상단의 별도 변환 버튼을 사용한다. 원본 보존 블록이 생길 수 있으므로 기존 서식을 계속 편집하려면 전환할 필요가 없다.

로컬 저장과 NAS 동기화 상태는 별도로 표시한다. 충돌 시 양쪽 본문을 비교하며 서버 버전·로컬 버전 중 하나를 선택해도 다른 내용은 이력 또는 사본으로 보존한다.

## 검증 범위

실제 WebKit에서 서식·표·첨부·체크박스·한국어 조합 입력·실행 취소·외부 요청 차단을 검사한다. 저장·첨부·충돌·원문 복원은 합성 NAS와 실제 SQLite로 검사한다. 공식 Note Station의 모든 위젯·도구를 복제한 것은 아니며 실제 NAS·다른 Mac 왕복 검증은 별도다.
