# LaTeX 수식 미리보기

[English](math-preview.md) | **한국어**

Markdown 미리보기에서 [KaTeX](https://katex.org/)로 수식을 표시한다. KaTeX 0.19.0과 글꼴을 앱에 포함하므로 인터넷 연결과 별도 설정이 필요 없다.

인라인 수식은 `$…$` 또는 `\(…\)`로 작성한다.

```markdown
질량과 에너지: $E=mc^2$
분수: \(\frac{a}{b}\)
```

블록 수식은 `$$…$$` 또는 `\[…\]`로 작성하며 여러 줄을 사용할 수 있다.

```latex
$$
\begin{aligned}
  x_i &= y_j + 1 \\
  a &= \frac{1}{2}
\end{aligned}
$$

\[\int_0^\infty e^{-x}\,dx = 1\]

$$\begin{pmatrix}a & b \\ c & d\end{pmatrix}$$
```

수식 예제를 그대로 보여주려면 위 예시처럼 코드 블록이나 인라인 코드를 사용한다. 제목, 목록, 표 셀, 링크의 표시 문구에도 인라인 수식을 쓸 수 있다. 긴 블록 수식은 가로로 스크롤할 수 있다. 잘못된 수식은 원문을 색으로 구분하고, 마우스를 올리면 오류 이유를 보여준다.

일반 금액의 `$`는 `\$`로 이스케이프한다. 수식 명령 지원 범위는 [KaTeX 공식 지원 목록](https://katex.org/docs/supported)을 따른다. 외부 이미지 로딩이나 HTML 삽입을 요구하는 신뢰 명령은 허용하지 않는다.

0.2.1 빌드 8부터 동기화 시 수식을 오프라인 PNG로 만들어 Note Station 웹에 일반 이미지 첨부로 표시한다. 정확한 TeX·구분자·줄바꿈은 Markdown 원문에 그대로 보존하며, v3 원문 첨부의 지문·이미지 매핑을 확인해 앱에서 다시 편집한다. 같은 수식의 이미지는 재사용하고 사용하지 않는 생성 이미지는 동기화 때 정리한다. 기본 이미지 최대 크기는 2048×2048이며 아주 큰 수식은 비례 축소된다. 잘못된 수식은 원문을 포함한 오류 이미지로 표시한다.

웹에서 본문을 수정해 원문 첨부가 더 이상 일치하지 않으면 HTML 서식 문서로 열어 웹 수정 내용을 유지한다. 원본 HTML 문서와 보존 블록 속 내용을 자동으로 수식으로 재해석하지 않는다. 2026-10-16 검증은 실제 WebKit 이미지 생성과 합성 NAS 왕복이며 실제 NAS 웹 표시를 다시 확인한 결과는 아니다.

포함 리소스를 갱신할 때는 공식 npm 배포본을 압축 해제한 뒤 `rtk proxy python3 script/bundle_katex.py /path/to/package`를 실행한다. 이 스크립트는 WOFF2 글꼴을 CSS에 포함하며 앱 빌드·실행 중 다운로드하지 않는다. 라이선스는 `Resources/KATEX-LICENSE.txt`에 포함한다.
