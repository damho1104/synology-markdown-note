# Synology Markdown Note 1.2.14 (빌드 25)

[English](1.2.14.md) | **한국어**

설정 → 진단 화면에서 진단 내보내기 메뉴의 이름과 배치를 정리했습니다. 기존 진단 자료와 로그 ZIP 내보내기 기능은 유지합니다.

## 변경 사항

- ‘개발자에게 전달할 진단 자료’ 섹션을 간결한 ‘내보내기’로 변경했습니다.
- ‘로그 회전·보관 → 진단 로그 → 내보내기’ 순서로 정리해 관련 작업을 연속해서 찾을 수 있습니다.
- ‘진단 자료 내보내기…’ 및 ‘로그만 내보내기…’ 버튼을 설명보다 위로 올렸습니다.
- DB 상태·무결성 검사와 로그 포함 범위, 개인정보 제외·식별자 익명화 안내는 계속 표시합니다.

## 검증

- Swift 전체 회귀 테스트 324개(35개 스위트) 통과. 진단 내보내기 관련 테스트 4개를 포함합니다.
- Python CLI 전체 테스트 100개 통과(`uv run --locked pytest -q tests`).
- Release DMG·ZIP, 앱 및 Credential Helper 서명, 체크섬은 릴리스 패키징 과정에서 검증합니다.

## 배포 범위

macOS 14 이상 Apple Silicon arm64 앱 DMG·ZIP과 Ubuntu 22.04/24.04 amd64 및 macOS arm64 CLI를 배포합니다. 앱은 기존 로컬 개발 인증서로 서명하며 Apple Developer ID 서명·공증은 포함하지 않습니다. 이번 변경은 설치된 앱이나 운영 NAS의 데이터에 영향을 주지 않습니다.
