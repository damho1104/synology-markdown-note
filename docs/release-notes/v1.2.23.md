# 한국어

## 웹 자동 저장 안내 수정

- 기존 노트 편집과 새 노트 생성의 일반 자동 저장 중에는 `NAS에 자동 저장 중…` 상태를 표시합니다.
- 노트 저장 결과를 확인할 수 없거나 확인이 필요한 편집본을 다시 열면 노란 경고와 복구 버튼을 표시합니다. 즐겨찾기 변경 중에도 이미 표시된 복구 안내가 유지됩니다.

# English

## Web autosave status fix

- Routine autosaves show a saving status while updating an existing note or creating a new one.
- The recovery warning and controls appear when a note save could not be confirmed or a draft that needs review is reopened. Changing a favorite keeps any existing recovery notice visible.
