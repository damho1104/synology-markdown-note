# Synology Markdown Note 1.2.0

**English** | [한국어](1.2.0.ko.md)

Apple Silicon (arm64), macOS 14 or later, build 11.

## New Features

- Display Synology Note Station stacks alongside notebooks. Supports creating, renaming, deleting, expanding, and collapsing stacks, and filtering notes by stack.
- Move one or more notebooks into or out of a stack. Supports drag and drop and context menus.
- Preserve the current selection after renaming a stack. Deleting a stack only removes membership, preserving notebooks and note bodies.
- Use the Notebook/Stack NAS APIs identified in the official Note Station Client 3.0.0-883. If a network response is lost, refetch server lists to prevent duplicate modification requests.
- Maintain per-account local data isolation and compatibility with existing SQLite notebook information, and prevent races with automatic uploads during stack operations.

Retains FTS5 advanced search, smart notebooks, note links, backlinks, and graphs from 1.1.0, and HTML editing, Markdown, and equation PNG synchronization from 1.0.0.

## Installation Files

- `SynologyMarkdownNote-1.2.0-arm64.dmg`: app installation image.
- `SynologyMarkdownNote-1.2.0-arm64.zip`: ZIP of the same app bundle.
- `SHA256SUMS`, `manifest.json`, `distribution.ko.md`: integrity checks, build information, and installation instructions.

Quit the existing app normally before replacing it. There is no need to delete or reset local notes, login information, or settings.

## Validation and Limitations

253 tests / 26 suites validated stack API call formats, refetching and lost responses, per-account membership, note preservation, and regression behavior. Release builds, read-only DMG mounting, ZIP extraction, nested signatures, and checksums are checked during distribution.

Stacks were implemented using the official client's internal APIs and synthetic NAS responses. Creating, modifying, and deleting stacks on a real NAS, interoperability with the official client, simultaneous editing on multiple Macs, and installation on another Mac have not yet been revalidated.

Signed with a local development certificate; no Developer ID signing or Apple notarization. Intel/universal builds are not provided.
