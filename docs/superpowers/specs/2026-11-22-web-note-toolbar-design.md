# 웹 메모 편집 툴바

## 동작

- 웹에서 새 메모는 지금처럼 Markdown으로 만든다. 저장된 Markdown 메모는 기존 편집기와 원문·분할·읽기 토글을 유지한다. Note Station에서 기본 서식으로 쓴 메모는 이 토글과 별도 편집 영역 라벨을 표시하지 않고, 제목 아래에 전체 툴바와 단일 본문 편집기를 바로 표시한다. 모드 전환이나 자동 변환을 추가하지 않는다.
- 스크린샷에 나온 문단 스타일, 글꼴·크기, 굵게·기울임·밑줄·취소선, 위·아래 첨자, 글자·강조 색, 네 가지 정렬, 글머리·번호·체크 목록, 들여쓰기·내어쓰기, 서식 지우기, 링크 삽입·해제, 표 삽입·행/열/표 편집, 첨부, 실행 취소·다시 실행을 지원한다. 제한된 선택이나 지원하지 않는 구조에는 해당 명령을 비활성화하거나 이유를 안내한다.
- 열기나 선택만으로 저장하지 않는다. 편집한 구간 밖의 원본, 기존 첨부와 참조를 보존한다. 암호화, 휴지통, 충돌 및 저장 결과 불확실 상태의 기존 제한과 Markdown 읽기 보기의 동작을 유지한다.
- 범위는 웹 클라이언트와 그 저장 경로다. 포럼 글, macOS 앱, CLI, 릴리스 및 운영 NAS는 변경하지 않는다.

## 접근

현재 구간 편집 방식을 확장한다. 서버는 노트 버전과 대상 구간을 검증하고 원본의 해당 부분만 바꾼다. 기존 첨부 전송·복구 흐름을 재사용하되 저장 형식은 바꾸지 않는다. 브라우저가 본문 전체를 직렬화하는 방식은 툴바를 만들기 쉽지만 수정하지 않은 서식·첨부가 바뀔 위험이 있어 제외한다.
