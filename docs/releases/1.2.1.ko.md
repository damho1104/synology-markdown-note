# Synology Markdown Note 1.2.1

[English](1.2.1.md) | **한국어**

Apple Silicon(arm64), macOS 14 이상, 빌드 12.

## 수정 사항

- 책장 생성·이동·이름 변경·삭제 시 자동 업로드 또는 NAS 새로고침이 진행 중이라도 최대 30초 동안 해당 작업 종료를 기다린 뒤 수행합니다. 책장 작업이 시작된 뒤 새로운 자동 동기화 작업이 끼어들지 않도록 예약합니다.
- 기다리는 동안 연결 또는 계정이 변경되거나 작업을 취소하면 NAS 쓰기를 시작하지 않고 종료합니다.
- 책장 만들기 창에서 실패 메시지를 직접 표시합니다. 진단 로그에 책장 작업의 시작·완료·실패 단계와 안전한 오류 코드만 기록합니다.
- 노트와 메모장, 기존 로그인·키체인 자격 증명, 데이터 저장 형식을 유지합니다.

## 설치 파일

- `SynologyMarkdownNote-1.2.1-arm64.dmg`: 앱 설치 이미지.
- `SynologyMarkdownNote-1.2.1-arm64.zip`: 같은 앱 번들의 ZIP.
- `SHA256SUMS`, `manifest.json`, `distribution.ko.md`: 무결성·빌드 정보·설치 안내.

기존 앱을 정상 종료하고 앱 번들만 교체합니다. 로컬 노트와 계정 설정을 초기화하지 않습니다.

## 검증 범위

합성 NAS 기반 회귀 검사에 자동 새로고침·업로드 경합, 연결 변경, 취소, 동시 책장 생성, 오류 기록 시 민감정보 배제 사례를 추가했습니다. 실제 NAS에서 책장 생성·이동이 성공하는지는 별도 실사용 검증이 필요합니다.

로컬 개발 인증서로 서명한 arm64 앱이며 Apple 공증 또는 Intel 빌드는 제공하지 않습니다.
