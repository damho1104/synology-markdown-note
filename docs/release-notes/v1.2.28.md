## 웹 편집과 자동 저장 개선

- 원본 HTML 노트에서 서식, 표 편집, 실행 취소와 다시 실행이 화면에 바로 반영됩니다. 자동 저장 중에도 선택한 글자에 서식을 적용하고 계속 편집할 수 있습니다.
- 본문 입력과 툴바 변경은 하나의 저장 큐에서 순서대로 NAS에 저장됩니다. 저장이 지연되어도 선택 범위와 그 뒤에 입력한 내용이 유지됩니다.
- 저장이 실패하면 편집본과 대기 중인 변경을 보존합니다. 저장 결과가 불확실할 때는 NAS 확인본과 대조한 뒤 남은 변경부터 이어갈 수 있습니다.

Docker Compose를 사용하는 경우, 기존 데이터 볼륨을 유지한 채 `1.2.28` 웹 이미지로 컨테이너를 다시 생성하세요.

## Web editing and autosave improvements

- Formatting, table edits, undo, and redo now appear immediately in original HTML notes. You can format selected text and keep editing while autosave is in progress.
- Text input and toolbar changes share one save queue and reach the NAS in order. A slow save preserves the selection and any text entered afterward.
- If a save fails, the draft and queued changes are preserved. If the outcome is uncertain, you can compare the draft with the NAS and resume from the remaining changes.

For Docker Compose, recreate the web container with the `1.2.28` image and keep the existing data volume.
