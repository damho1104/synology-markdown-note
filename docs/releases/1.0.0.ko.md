# Synology Markdown Note 1.0.0

첫 1.0 릴리즈. Apple Silicon(arm64), macOS 14 이상, 빌드 9.

## 주요 기능

- 기존 Note Station HTML 문서를 Markdown 변환 없이 서식 편집한다. 글꼴·색상·목록·링크·체크박스·표·이미지·실행 취소를 지원한다.
- Markdown 소스·분할 미리보기·읽기 모드, 오프라인 Mermaid·KaTeX, 이미지 붙여넣기와 파일 가져오기·내보내기를 제공한다.
- 수식을 일반 PNG 첨부로 동기화하고 정확한 Markdown 원문·TeX 구분자·코드의 역슬래시·줄바꿈을 보존한다.
- 자동 업로드, 오프라인 본문·첨부 보관, 검색, 태그·즐겨찾기, 메모장·휴지통·수정 이력 관리.
- 비밀번호·기기 토큰의 Keychain 보관, OTP·자동 로그인과 연결 복구.
- 충돌과 응답 유실을 구분하며 업로드 완료가 후속 편집·실행 취소를 덮지 않도록 보호한다.

## 설치 파일

- `SynologyMarkdownNote-1.0.0-arm64.dmg`: 앱을 Applications로 복사하는 설치 이미지.
- `SynologyMarkdownNote-1.0.0-arm64.zip`: 같은 앱 번들의 ZIP.
- `SHA256SUMS`, `manifest.json`, `distribution.ko.md`: 체크섬·빌드 정보·설치 안내.

기존 앱을 정상 종료한 뒤 교체한다. 노트 데이터와 계정 설정을 삭제할 필요가 없다. 릴리즈 패키지에 개인 노트·계정·비밀번호·서명 개인 키는 포함하지 않는다.

## 검증과 제한

전체 회귀 검사 223개 / 23개 스위트, 실제 WebKit 서식·수식 PNG 렌더링, 합성 NAS 왕복, SQLite 보존과 앱 재실행을 확인했다. Release 패키지는 DMG 무결성·읽기 전용 마운트·ZIP 추출·중첩 서명·체크섬을 검사한다.

로컬 개발 인증서로 서명했으며 Developer ID 서명·Apple 공증은 받지 않았다. 다른 Mac 설치, Intel/universal, 실제 NAS 웹에서의 최신 왕복과 여러 Mac 동시 편집은 별도 검증이 필요하다. 암호화 노트 편집·QuickConnect ID 탐색·인증서 검증 우회는 지원하지 않는다. 병합된 표의 구조 변경은 차단하고 지원하지 않는 위젯은 원본을 보존한다.
