## 웹 Markdown 노트에 파일 첨부

편집 가능한 Markdown 노트에서 스크린샷을 붙여넣거나 파일을 끌어 놓거나 **파일 추가…**를 선택할 수 있습니다. 지원하는 이미지는 미리보기에 표시되고, 일반 파일은 다운로드 링크로 삽입됩니다. 파일당 최대 **50MB(50,000,000바이트)**를 지원합니다.

첨부는 웹 서버에 암호화된 상태로 임시 보관되며 노트 자동 저장과 함께 NAS로 전송됩니다. 웹 서버에서의 업로드 완료와 NAS 저장 완료는 각각 표시됩니다.

### 저장 결과가 불확실할 때

- Note Station에서 저장 결과를 확인한 뒤 웹에서 보류를 해제할 수 있습니다. 기존 첨부 요청은 자동 재전송되지 않습니다.
- 보류를 해제한 임시 첨부는 **7일 동안** 내려받거나 직접 폐기할 수 있습니다. 기한이 지나면 다음 업로드 때 정리됩니다. 임시 복사본을 폐기해도 NAS에 저장된 파일은 유지됩니다.
- 확인한 NAS 버전에서 편집을 이어갈 수 있습니다. 기존 노트의 편집을 재개할 수 없으면 본문을 보존한 별도 초안을 열고 필요한 파일을 다시 선택할 수 있습니다.

리버스 프록시를 사용하는 설치는 요청 본문을 최소 50,000,000바이트까지 허용해야 합니다. 웹, macOS, CLI의 공통 버전은 `1.2.22`이며, 첨부 추가 기능은 웹 클라이언트에 적용됩니다.

로컬 브라우저에서 파일 선택·붙여넣기·드롭을 검증했고, 로컬 서버에서 정확히 50MB인 파일의 업로드·다운로드 및 1바이트 초과 차단을 확인했습니다. 실제 NAS에서 50MB 업로드와 Note Station·macOS 재조회 검증은 남아 있습니다.

## File attachments in web Markdown notes

In an editable Markdown note, paste a screenshot, drop a file into the editor, or use the attachment picker. Supported images appear in the preview and other files are inserted as download links. Each file can be up to **50 MB (50,000,000 bytes)**.

The web server encrypts temporary attachment copies and transfers them to the NAS when the note autosaves. The editor shows when the web upload completes and when the NAS save is confirmed.

### Recovering from an uncertain save

- Check the result in Note Station before clearing the hold in the web client. The original attachment request is never retried automatically.
- Once you clear the hold, you have **seven days** to download or discard the temporary copies. The next upload reclaims expired copies. Discarding a temporary copy leaves any file already saved on the NAS intact.
- Resume editing from the verified NAS version. If the original note cannot be edited yet, you can open a separate draft with the preserved text and select any files you still need.

If you run the web client behind a reverse proxy, allow request bodies of at least 50,000,000 bytes. The web, macOS, and CLI clients share version `1.2.22`. This release adds attachment editing to the web client.

File selection, paste, and drop were checked in a local browser. The local server accepted and returned a file of exactly 50 MB and rejected an upload one byte over the limit. A 50 MB upload to a real NAS and readback in Note Station and macOS remain unverified.
