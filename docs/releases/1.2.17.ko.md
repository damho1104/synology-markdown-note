# Synology Markdown Note 1.2.17 (빌드 28)

[English](1.2.17.md) | **한국어**

새 노트 생성·저장 및 NAS 노트 열기에서 화면이 응답하기까지 걸리는 대기를 줄였습니다.

## 변경 사항

- 새 노트를 로컬에 저장한 뒤 편집 세션과 목록을 바로 반영합니다. 저장 이후 스마트 검색·그래프의 전체 재계산은 뒤에서 처리하며 연속 변경은 모아서 갱신합니다.
- 노트 저장 후에도 변경된 제목·목록·그래프 노드를 먼저 반영하고, 스마트 메모장 결과와 연결 관계를 후속 갱신합니다.
- 전체 목록을 갱신할 때 노트 요약을 중복으로 읽지 않도록 개선했습니다. 이전 갱신 결과가 더 최신인 로컬 변경이나 다른 계정의 화면을 덮어쓰지 않게 합니다.
- NAS 본문 다운로드를 기다리지 않고 노트 선택을 완료합니다. 본문을 가져오는 상태를 표시하며 같은 편집 세션의 중복 다운로드를 방지합니다.
- 즐겨찾기·휴지통 변경은 본문 다운로드 완료 후 적용하여 빈 본문 저장과 잘못된 동기화 충돌을 방지합니다. 본문이 없는 상태에서는 직접 편집을 보류합니다.
- 진행 중인 본문 다운로드는 함께 기다리고, 실패한 다운로드는 후속 작업에서 다시 시도할 수 있도록 정리합니다.
- 로컬 저장·수정 이력·전송 대기열, 동기화 충돌 및 불확실한 쓰기 결과를 보호하는 기존 절차를 유지합니다.

## 검증

- 새 노트의 즉시 표시, 로컬 저장·이력·전송 대기열 유지, 저장 후 스마트 검색·그래프 갱신 및 계정 전환 보호를 검증합니다.
- NAS 응답을 보류한 상태에서도 노트 선택이 먼저 완료되고 본문 요청이 중복되지 않는지 검증합니다.
- 기존 릴리스 준비 과정에서 Swift 전체 회귀 테스트 335개(36개 스위트)와 CLI 테스트 100개가 통과했습니다. GitHub 배포용 바이너리와 서명·체크섬은 별도로 검증해야 합니다.
- 로컬 테스트의 1,200개 노트·스마트 검색 2개 조건에서 새 노트 생성은 약 2.3ms였습니다. 실제 NAS 응답 시간이나 모든 환경의 체감 속도를 나타내는 수치는 아닙니다.
- 실제 설치된 앱 교체 및 사용자 NAS 데이터 변경은 수행하지 않습니다.

## 배포 범위

macOS 14 이상 Apple Silicon arm64 앱 DMG·ZIP과 Ubuntu 22.04/24.04 amd64 및 macOS arm64 CLI를 배포합니다. 앱은 로컬 개발 인증서로 서명하며 Apple Developer ID 서명·공증은 포함하지 않습니다.
